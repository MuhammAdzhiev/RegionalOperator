Виды цен

Справочник предназначен для регистрации видов цен, которые применяются на предприятии.. В классификатор включаются правила расчета цен продажи, закупки и других цен, используемых на предприятии.

Значения по умолчанию

Значения по умолчанию
  • Валюта. Значение по умолчанию, которое будет подставляться при выборе вида цен в документе.
  • Цена включает НДС. Значение по умолчанию, которое будет подставляться при выборе вида цен в документе.
